# Desarrollo de Software Cloud — UTN FRLP

Repositorio de materiales de la materia **Desarrollo de Software Cloud** de la
Universidad Tecnológica Nacional, Facultad Regional La Plata. Cursada **2026**.

## Contenido

| Archivo | Descripción |
| --- | --- |
| `ACUERDO DE CURSADA 2026.pdf` | Acuerdo de cursada: condiciones de aprobación, asistencia y evaluación. |
| `Calendario Desarrollo de Software Cloud 2026 - UTN FRLP.pdf` | Cronograma de clases, entregas y fechas de evaluación del ciclo 2026. |
| `TPI - Desarrollo de Software Cloud.pdf` | Consigna del Trabajo Práctico Integrador. |
| `Clases/` | Material de cada clase (presentaciones, apuntes, ejemplos). |

## Estructura

```
.
├── Clases/
│   └── Clase0-Cloud.pptx
├── ACUERDO DE CURSADA 2026.pdf
├── Calendario Desarrollo de Software Cloud 2026 - UTN FRLP.pdf
└── TPI - Desarrollo de Software Cloud.pdf
```

## Convenciones

- Una carpeta `Clases/ClaseN-<tema>` o archivo `ClaseN-<tema>.<ext>` por clase,
  numeradas desde `Clase0`.
- Commits siguiendo [Conventional Commits](https://www.conventionalcommits.org/):
  `docs:` para material y documentación, `chore:` para configuración del repo.
- Los cambios se integran a `main` vía Pull Request.
